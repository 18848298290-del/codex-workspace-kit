# 代码审查

默认只读，未获明确要求不修改文件。

1. 明确审查基线与变更范围，读取差异和必要上下文。
2. 聚焦可复现、可操作的正确性、安全性、性能和兼容性问题。
3. 对每项发现说明严重级别、文件位置、触发条件和修复方向。
4. 区分确定问题和待验证风险，不把风格偏好当缺陷。
5. 中文输出，按严重程度排序；无明确发现也要如实说明。
