# API 开发

1. 理解现有路由、鉴权、模型、数据流和接口契约。
2. 明确输入输出、错误码、兼容性、限流和权限边界。
3. 优先复用项目现有约定实现，避免引入额外框架。
4. 覆盖正常、错误、未授权及边界参数路径的测试。
5. 不写入真实凭据，不未经确认改动生产数据结构。
6. 中文说明接口变更、兼容性及验证方式。
